# artist-landing_page-TeresaB
Official website for Teresa Bissoo - Artist Landing Page

## Design Notes

Sections are not set to a fixed full-viewport height (`min-height: 100vh`). 
This was a deliberate choice: testing that approach caused excessive empty 
space on shorter sections (e.g. Upcoming Shows, Contact), which looked 
unfinished rather than intentional. I prioritized visual quality and content 
density over strict viewport-height sections for this version.
